# You're the Ref

A daily sports-rulings game: watch the play, make the call, see the official ruling. One call each from the NFL, NBA, NHL, MLB, PGA and lacrosse.

- `index.html` is the whole game (single file, no build step). Served with GitHub Pages.
- `leaderboard/Code.gs` is the Google Apps Script behind the leaderboard. Its web app URL goes in `LB_URL` near the top of the game script in `index.html`.

Plays are illustrations, not real games. Not affiliated with any league.
